# Historial de versiones

## v1.0.2
- Se corrigió el control de cierre de la barra lateral para escritorio y móvil.
- Se implementó el desplegable del selector MARKET TERMINAL con estado de proveedores y accesos rápidos.
- Se preservó el resto de la navegación y funcionalidad existente.

## v1.0.1
- Se ajustó el comportamiento de la barra lateral para escritorio y móvil.
- Se amplió la actualización manual para volver a consultar los datos de mercado y FX.
- Se hizo funcional el acceso de información del proyecto desde el distintivo MP.

## v1.0.0
- Primera versión integrada de frontend React, API Express, proveedores públicos Binance y Frankfurter, análisis probabilístico empírico e interfaz de comparación.

> Este historial resume los cambios entregados en las versiones del proyecto. La compilación y validación de despliegue deben registrarse por separado cuando se ejecuten.
