# Revisiones individuales

La rúbrica solicita que cada integrante revise el repositorio y comente: lenguaje utilizado, base de datos, estado de recopilación/gestión de datos, y funcionalidades implementadas y pendientes.

Cada persona debe:
1. Abrir su archivo individual.
2. Verificar que la información coincide con su revisión real del repositorio.
3. Completar la sección de análisis y describir su aporte real al proyecto.
4. Añadir enlaces a sus Issues, Pull Requests, commits y evidencias.
5. Guardar y publicar el cambio con su propia cuenta GitHub.

Los datos técnicos comunes están precargados como punto de partida; el integrante debe validarlos y añadir su valoración. No copiar la revisión de otro compañero ni declarar trabajo que no se haya realizado.
