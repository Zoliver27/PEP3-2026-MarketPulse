El archivo contiene las capturas compartidas por el equipo y puede abrirse o descargarse directamente desde GitHub. No se debe volver a marcar esta actividad como pendiente de carga. La revisión de cada pantalla debe limitarse a lo que realmente aparece en el documento.

El ZIP v1.0.2 compartido contiene una implementación del comparador con dos series de precios normalizadas a Base 100 y alineadas por marca temporal. Esa inspección de código no sustituye una validación end-to-end de la aplicación en ejecución.

## Criterio de autenticidad

Una captura demuestra únicamente lo que se ve en pantalla en ese momento. No sustituye a pruebas automatizadas, al historial de commits ni a la revisión individual. No utilizar datos inventados ni incluir tokens, archivos `.env`, credenciales o información personal.

Para consultar las evidencias, abrir el PDF versionado en esta carpeta.
